# USB 스피커 v2 (갤럭시 → PC 스피커)

PC 소리를 USB-C 케이블로 폰에 보내서 폰을 스피커로 씁니다. 루팅 필요 없음.

## v2에서 달라진 점
- **PIN 인증**: PC 창에 뜨는 6자리 PIN을 폰에 입력해야 연결됩니다.
  같은 네트워크의 다른 기기가 몰래 소리를 가로채는 걸 막습니다.
  (PIN 자체는 네트워크로 전송되지 않는 방식 - HMAC 챌린지 응답)
- **PC 프로그램에 창(GUI)**: PIN 표시, 연결 상태, 음소거, 장치 다시 불러오기
- **기본 출력 장치 자동 재감지**: PC에서 스피커/이어폰을 바꿔도 자동으로 따라감
- **지연 모드 3단계**: 저지연 / 균형 / 안정
- **소리 증폭(0~10dB)**: 폰 스피커가 작게 느껴질 때
- **이퀄라이저**: 프리셋(Rock, Pop, Jazz 등) 또는 대역별 직접 조절, 재생 중 즉시 반영
- **실시간 통계**: 전송 속도와 버퍼(지연) 표시
- **알림에서 바로 중지** 버튼

## 1. 프로그램 만들기 (GitHub가 대신 빌드)
1. github.com 가입 후 로그인
2. 오른쪽 위 [+] → New repository → 이름 입력(예: usb-speaker) → Create
3. "uploading an existing file" 클릭 → 압축 푼 폴더 안의 내용(.github, android, pc, README.md)을 전부 끌어다 놓기 → Commit changes
4. 위쪽 [Actions] 탭 → 빌드가 끝날 때까지 대기(5~10분, 초록 체크 표시)
5. 완료된 빌드를 눌러 아래 Artifacts에서 두 개 다운로드
   - phone-app-apk → 폰용 앱
   - pc-program-exe → PC용 프로그램

## 2. 설치
- 폰: APK를 폰으로 옮겨 실행 → "출처를 알 수 없는 앱" 허용
  - 설치가 막히면: 설정 → 보안 및 개인정보 보호 → 자동 차단 끄기
- PC: UsbSpeakerPC.exe 실행
  - "Windows의 PC 보호" 창 → 추가 정보 → 실행
  - 방화벽 창이 뜨면 **개인 네트워크와 공용 네트워크 둘 다 체크** 후 허용

## 3. 사용
1. 폰을 USB-C로 PC에 연결
2. 폰: 설정 → 연결 → 모바일 핫스팟 및 테더링 → USB 테더링 켜기
3. PC: UsbSpeakerPC.exe 실행 → 창에 PIN 6자리가 보임
4. 폰: USB 스피커 앱 → PIN 입력 → [시작]

PIN은 exe를 켤 때마다 새로 만들어집니다. 폰에는 마지막 입력이 저장되므로,
exe를 다시 켰다면 새 PIN으로 바꿔 입력하세요.

## 문제 해결
- "PC 찾는 중"에서 멈춤 → 방화벽에서 공용 네트워크 허용이 빠졌을 가능성이 큼
- "PIN이 올바르지 않습니다" → PC 창의 PIN을 다시 확인 (exe 재시작 시 PIN 변경됨)
- 화면 꺼지면 끊김 → 설정 → 애플리케이션 → USB 스피커 → 배터리 → 제한 없음
- 소리가 뚝뚝 끊김 → 지연 모드를 "안정"으로 변경
- 이퀄라이저가 안 먹는 것 같음 → 이퀄라이저 스위치가 켜져 있는지 확인
